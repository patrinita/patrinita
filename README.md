The portrait turns my photo into text characters.
An SVG animation reveals them row by row.

Want to try it? Explore the scripts in 
[this repository](https://github.com/patrinita/patrinita/tree/main/scripts):

- [`make_portrait.py`](scripts/make_portrait.py) converts a photo into an ASCII portrait;
- [`stats.yml`](.github/workflows/stats.yml) runs the workflow for generating GitHub stats.

Design and scripts adapted from
[Andrii Drok's profile](https://github.com/andriidrok1/andriidrok1).
